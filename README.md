# 内嵌的临时Tomcat对照项目

本项目为一个 ** Tomcat 项目**，其存在同时作为 **父 Spring Boot 项目** 的等价对照物（即用于功能、行为或性能的对比验证）。

## 项目性质
- **类型**：传统 Servlet 容器（Tomcat）部署结构
- **生命周期**：临时
- **对标项目**：[ujsp](https://github.com/frycod128/ujsp)

## 关于更新
项目发生更新时：
1. **本项目将被归档** (内容部分，环境不会)
2. 归档方式：转为非主（例如 `archive_test1`）分支
3. 归档后，项目将更新主分支作为新需求的活跃开发环境使用
